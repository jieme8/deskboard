四环保留，外观换成弹药库那套

四格等权圆环还在，但外观完全走 DeskBoard 的弹药库语言。这一版重点把 HUD 无边玻璃做成真正的仪器： 分段刻度环、雷达扫描、瓷砖扫描线、呼吸 LED、弧端光点——不加底板也能看出在运行。其他三档保持静态。

四档外观

和系统状态卡、活动监视器共用同一套 DeskStyle。电池不新造皮肤，只换颜色和内容；常驻动效只在 HUD 档出现，其余三档保持静止。

无边玻璃 · 动效拆解

HUD 档不加底板、不加边框，靠分段刻度、雷达扫描、扫描线、呼吸 LED 和弧端光点表达科技感；空槽不参与动效。

01分段刻度环

80% → 26/32 格点亮；切换状态时按 10ms 逐格上电，弧端光点 3s 呼吸。

02雷达扫描

环内 conic 扫描 6s 一圈，只在有设备的瓷砖里出现。

03瓷砖扫描线

6s 一拍，前 2.4s 从环顶扫到环底；四格错峰 0.25s，空槽不扫。

04LED 双脉冲

6s 一拍，前 2.5s 双闪；正常青、低电琥珀、过低红，档位直接换色。

05顶线数据流

3s 循环，像数据包沿瓷砖顶线流过；HUD 的「无边框」靠这条线立住。

动效只在 HUD 档：约 24fps，隐藏即停；菜单「HUD 动效」可关（BatteryHUDMotion）。其余三档仍是静态，避免整块桌面都在动。

六种状态

本机固定占第一格，其余三格给外设；空槽只代表外设未连接。六种状态统一用 HUD 档演示，方便同时看动效和档位色。

悬停：细节不占瓷砖

悬停演示也用 HUD 档：瓷砖顶线提亮，气泡仍是应用的深色玻璃。设备名、状态、剩余/充满时间、健康度、AirPods 左右耳与盒，全部放 250pt 气泡。

  • 存档键：BatteryHidden / BatteryStyle / BatteryPlaces / BatteryHUDMotion。
  • 摆位：新增 DeskPlaceKindBattery；右上角 + dy 174，走现有夹紧逻辑。
  • 锁定：和其余四块共用 LayoutLocked；上锁时电池卡也落档。
  • 点击：有设备的瓷砖打开对应系统设置；按住移动超过 3pt 仍是拖组件。
  • 采样：本机 30s、Magic 外设 60s、AirPods 120s；插拔电源立即刷新，隐藏时暂停。
  • 不做：充电上限/充电管理没有公开 API，只提供「打开电池设置」深链，不画假开关。

和数据源的对应

能读到的进瓷砖，读不到就留空；所有「未知」都印「—」，不印 0。

  • 内建电池：复用 DeskStats 的 IOPS 读数（百分比 / 交流电 / 充电 / 充满 / 剩余分钟），健康度走 AppleSmartBattery（设计容量、循环次数、温度）。本机实测 80% · 交流电 · 未充电。
  • Magic 外设：IORegistry AppleDeviceManagementHIDEventService 的 BatteryPercent，60 秒一采，零权限。
  • AirPods：system_profiler -json SPBluetoothDataType 后台 120 秒一采，解析左/右/盒；解析失败只影响这一格，不影响其余三格。
  • iPhone / Apple Watch：原生组件走 Continuity/iCloud 私有通道，没有公开接口；本方案不做，也不画假数据。
  • 顺序：内建电池固定第一格，之后是 AirPods → 蓝牙耳机 → Magic Mouse → Magic Keyboard → Magic Trackpad → 其他 HID；超过 4 个取前 4，悬停提示「还有 N 个」。

改动落点

设计确认后再动代码；下面是这次会碰到的文件。

  • battery.h / .m — 设备模型、优先级、内建电池健康度、Magic 外设与 AirPods provider。
  • battery_view.h / .m — 364 × 142 仪表瓷砖、四角准星、档位色、空槽/未知、悬停气泡、点击设置；HUD 档单独一套分段刻度与动效层。
  • main.m — 第五块窗口组、菜单、BatteryPlaces、BatteryHUDMotion、锁定、屏幕变更、点击/拖动。
  • places.h — 新增 DeskPlaceKindBattery，默认右上 + dy 174。
  • tools/preview_battery.m — 离线输出六种状态 × 四档外观。
  • tools/verify_battery.m — 瓷砖等宽、环径/线宽、百分比居中、档位阈值、未知印「—」、优先级截断。
  • tools/dump_window.m — 按 364 × 142 识别电池窗，和 272 × 142 / 560 × 330 区分。
  • build.sh / README.md — 编译清单、组件说明、菜单表。
验收底线：本机真机必须出「1 块亮瓷砖 80% + 3 块虚线空槽」，和参考图的四格布局同构；只有 HUD 档有常驻动效，约 24fps，隐藏即停，菜单可关。
老卡片先不动：系统状态卡表尾的电池文字暂时保留，避免牵动已验证版面；新组件跑稳后再单独讨论要不要撤掉，免得同一块屏两处各写一个电池数。
