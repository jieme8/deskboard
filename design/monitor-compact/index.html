打开原生活动监视器
  • 存档键：MonitorCompact（BOOL），默认关；重启保持。
  • 切换动作：重建监视器窗口，按当前屏的角 + 16pt 边距重新落位；右下角不漂。
  • 调角：四角位移是点偏移，和尺寸无关；切换时若在调角模式则先退出，位移保留。
  • 悬停：切换时关掉旧气泡，下一次悬停按新格几何重新命中。
  • 锁定 / 隐藏：照旧；锁定只禁拖动，不影响开关和悬停。
  • 采样：仍是 10 秒一拍，不降频；进程榜照常排前 4、12h 照常按拍算好，只是少画 12 行。切回完整模式不会出现 12h 空窗。

行底条换了尺

完整模式里条长是「相对本榜前 4 名的峰值」；只剩一行时，这个尺子会让每根条都顶满，所以简略模式改成「占该格榜头那个分母的份额」。

指标条长 =分母（榜头已经写着）
CPU该进程占整机 / 100整机 37%
内存RSS / 物理内存16.4/24 GiB
能耗该进程能耗 / 全部进程能耗前4名占全部 69%
网络该进程速率 / 系统总速率系统 ↓1.2M ↑340K
  • 非零值最小画 3pt，避免 1.7% 这种小值在 2pt 条上消失；数值本身仍然精确。
  • 未知（哨兵 -1）或分母 ≤ 0 时不填，只留槽；照旧不印假 0。
  • 网络进程速率可能因可读进程覆盖差异略高于系统总量，条长夹在 0–1。
  • 没有任何可读进程时，进程行显示「没有更多活动」，条只留槽，不伪造名字。

保留 / 收起 / 新增

简略不是另做一块组件：数据、取色、悬停、双击、拖动、锁定、形变全部沿用同一条路。

保留 KEEP

  • 四格指标顺序：CPU 左上、内存右上、能耗左下、网络右下。
  • 榜头总量与完整模式同一套字符串、同一把尺。
  • 进程名、现在值、单位、哨兵规则、<0.1% 规则。
  • 悬停整格（120 × 55）弹气泡：全名、pid、单核口径、12h 平均 / 累计、介绍、出处。
  • 双击整格打开原生活动监视器；整块任意处拖动（双击除外）。
  • 四档外观、四角形变、全局锁定、显示 / 隐藏、多屏摆位。

收起 DROP / 新增 NEW

  • DROP 每榜第 2–4 名；只画第 1 名。
  • DROP 「进程 / 现在 / 12h」列名和 12h 文字列。
  • DROP 格内图标（120pt 宽放不下，指标色由榜头数字承担）。
  • DROP 完整模式的「相对峰值」条尺。
  • NEW 占总量份额的 2pt 行底条。
  • NEW 菜单「简略模式」勾选项 + MonitorCompact 存档。
